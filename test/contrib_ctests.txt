# test/contrib_ctests.txt — the contrib libraries scripts/contrib_ctest.sh runs.
#
# One path per line. Explicit rather than a glob: a glob that skips what will
# not compile reports green over a set that shrank, and this list exists
# because `contrib/toml` spent the project's whole history unable to produce
# C that compiles while its self-tests passed under the interpreter.
#
# What is NOT here: anything declaring `extern fn` for a symbol the compiler
# does not emit itself (there is no linkable definition to run against), and
# files that are module fragments rather than programs -- contrib/graphql's
# lexer, parser and printer only parse once `ast.mere` is imported, and
# `exec.mere` is the entry point that imports them all.
#
# Add a line when a library is added, and raise EXPECT in the script with it.

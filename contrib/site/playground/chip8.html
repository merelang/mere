CHIP-8, written in Mere

A CHIP-8 CPU emulator compiled to WebAssembly from chip8.mere. The same fetch-decode-execute core runs on all four Mere backends; here it renders to a <canvas> and is driven by a per-frame callback (dom_on_frame, a requestAnimationFrame binding added to contrib/dom for this dogfood). The built-in ROM cycles the hex-digit glyphs 0..F, paced by the delay timer.

The ROM lives in the module as a bytes value (loaded into 4 KB of emulated memory at 0x200); opcodes are decoded with the bitwise builtins and sprites are XOR-blitted into a 64×32 framebuffer. Keyboard input is wired through dom_on_key onto the CHIP-8 hex keypad (1 2 3 4 / q w e r / a s d f / z x c v).

frontend FFI dogfood — a real-time loop via dom_on_frame

Mere chat

Server-Sent Events demo, Mere on both ends. Every open tab holds a long-lived GET /sse/chat connection; when anyone POSTs a message, the Mere handler pushes a data: {...} frame out to every subscriber. Open this page in two tabs to see it live. The browser half is app.mere compiled to Wasm — there is no application JavaScript on this page, only the contrib/dom host glue.

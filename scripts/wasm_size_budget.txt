# scripts/wasm_size_budget.txt -- bands for the .wasm the docs site ships.
#
# One line per file: <name> <floor> <ceiling>, in bytes.
# scripts/wasm_size_check.sh builds the site and fails outside the band.
#
# These are NOT targets. Each is the size measured on 2026-09-12, -10% / +10%.
# The ceiling is tight enough that the 2026-07 -> 2026-09 tripling of
# hello.wasm (5.2 KB -> 15.0 KB) would have failed here long before anyone
# noticed it by eye. The floor exists because a demo that collapses to a stub
# is a failure that a ceiling-only check calls a pass, forever -- the reasoning
# is scripts/budget_check.sh's, and test/budget/BUDGETS says it at length.
#
# Moving a band is a decision, not maintenance: say why in the commit.
